AEGLOS Analytics Pro

Multi-Domain HUMINT/OSINT/GEOINT Intelligence Fusion Platform. Combines human intelligence patterns, open-source intelligence collection, and geospatial threat analysis with military-grade AI/ML.

Quick Start

cd ~/aeglos-analytics
./start-dev.sh

# API: http://localhost:8000
# Web: http://localhost:5000
# GeoThreat: http://localhost:5000/geothreat
# API Docs: http://localhost:8000/docs

HUMINT Capabilities

Human Intelligence indicators extracted from open-source reporting:

  • Pattern-of-life analysis from public movement/activity data
  • Social network mapping from open-source social media
  • Sentiment and rhetoric analysis from public statements
  • Leadership activity indicators from press coverage
  • Defector/emigrant population movement indicators

Core API Endpoints

GET
/health
System health check. Returns service status, ML training state, GeoThreat availability.
POST
/ingest
Ingest batch of data points. Body: {"data": [...]} (max 100,000 points)
POST
/analyze
Run ML analysis (anomaly + classification). Body: {"data": [...]}
GET
/forecast?hours=72
72-hour threat forecast with confidence bands and peak windows.
POST
/encrypt
AES-256-GCM encrypt. Body: {"plaintext": "...", "password": "..."}
POST
/decrypt
Decrypt AES-256-GCM payload. Body: {"payload": {...}, "password": "..."}
GET
/metrics
Pipeline and ML model metrics.
GET
/benchmark?points=100000
Run ingestion + encryption benchmark.

GET

Regional threat analysis with event counts by severity.

ML Engine

Two-model pipeline trained on synthetic multi-domain intelligence feature vectors:

Features: event_rate, severity_score, geo_spread, source_diversity,
          temporal_cluster, confidence_avg, keyword_density, repeat_rate

Anomaly Detection: IsolationForest (200 estimators, 5% contamination)
Classification:    RandomForest (300 estimators, max_depth=12, balanced)
Training:          5,000 synthetic samples (80/20 train/test)
Target Accuracy:   99.7%

Encryption

Algorithm:  AES-256-GCM (authenticated encryption)
KDF:        PBKDF2-HMAC-SHA256, 100,000 iterations
Salt:       16 bytes random per operation
Nonce:      12 bytes random per operation (96-bit GCM nonce)
Auth tag:   128-bit GCM authentication tag

Deployment

Development

./start-dev.sh    # Start both servers
./stop.sh         # Stop both servers

Production (systemd)

sudo cp deployment/aeglos-api.service /etc/systemd/system/
sudo cp deployment/aeglos-web.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now aeglos-api aeglos-web

Docker

docker-compose up -d
